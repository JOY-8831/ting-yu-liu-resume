# GitHub Pages update

1. Extract this ZIP.
2. Open the `github-pages-update` folder.
3. Upload **everything inside it** to the root of `JOY-8831/ting-yu-liu-resume`.
4. When GitHub asks about existing files, keep the new replacement versions.
5. Commit with: `Configure GitHub Pages deployment`.
6. Open the repository's **Actions** tab and wait for **Deploy portfolio to GitHub Pages** to finish.
7. Then open `https://joy-8831.github.io/ting-yu-liu-resume/`.

The hidden `.github` folder is required. Make sure it is included in the upload.
